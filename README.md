# interviewscam

Community registry of fake job-interview scams that target developers (interviewscam.com).

The MVP is specified in [docs/SPEC.md](docs/SPEC.md). That file is the source of truth, and anything not written there is not agreed.

To build and check the site locally, run `bash tools/check.sh`; prerequisites and details are in [CLAUDE.md](CLAUDE.md).
