Called with the page; returns (dict "image" "alt" "size" "lines" ). Every page but a record's own page gets the site card: the brand, then the site description. A report's own page gets its report card: the chip line (the D6 state chip and the name type), the name as it renders (a visible persona with its D10 label, a hidden one as the placeholder), the D6 state sentence, the D7 label and the brand; a campaign's own page its campaign card: the type, the name, the first and last seen dates and the brand. The candidates are the record card at each name size of hugo.Data.preview.record.name_sizes, in order, and the site card last. The first candidate whose every block has lines (preview-wrap.html gives false for a character the font tables lack, and no lines for no text) and whose blocks fit the content box is drawn, so a record whose name the font cannot draw, or that fits at no size, gets the site card (part 8). The site card always fits; if it did not, the build fails (errorf) instead of drawing a card that lost text. One images.Filter call over one slice of filters, from the 1 x 1 base image: the ground grows it to 1185 x 631 (the first padding), the second padding crops the base pixel away (1184 x 630), the third adds the bar at the left edge (1200 x 630), then one images.Text per line. Every number comes from data/preview.toml; lines start at the margin, a block's lines follow at its line pitch, the font's own line height ceil((ascender - descender + lineGap) x size / unitsPerEm), and blocks are a gap apart. The fonts reach images.Text fingerprinted: Hugo names a drawn image by the font's resource path, so the SHA-256 in that path gives a card drawn with other font bytes another address (ADR-0009 part 4). The alt is preview.alt_site, alt_report or alt_campaign over every drawn block in drawing order, so it holds the image's whole text. sitecheck preview_card is the replica of this partial (render rule 21, the pixel check); preview-fit/ compares the two.
